# P. Marmoratum ARGs
Repo for the different scripts run to generate ARGs on the marbled four eyed frog

These scripts were generated by Eddie Cortes under the supervision of Dr. Emma Steigerwald and Dr. Rasmus Nielsen

## How to run

To prep a vcf file to run, use the call.sh script by running ```bash call.sh```
Note: The update the file paths to match where VCF files are stored on your machine.
